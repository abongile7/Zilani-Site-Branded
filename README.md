# M. Zilani Attorneys Portal Demo

A self-contained browser simulation for client intake, matter management, paper-file migration, OCR summaries, document search, voice notes, consultations, user invitations, and communication logs.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Demo access

- Administrator: `admin@zilani.demo` / `admin123`
- Lawyer/staff: `lawyer@zilani.demo` / `law123`

## Important

This is a front-end simulation. Authentication, case records, document data, and notifications are stored locally in the browser and are not production legal systems. Do not enter real client or matter information.
